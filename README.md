# 線上問事預約系統 - 設定與部署教學

這份教學假設你完全沒有架站經驗，請照順序一步一步做。

---

## 第一步：建立 Google 試算表（當作資料庫）

1. 到 [Google 試算表](https://sheets.new) 開一個新的空白試算表
2. 隨便取個名字，例如「問事預約資料庫」
3. **不用自己建欄位**，等一下程式會自動建立表頭

---

## 第二步：貼上後端程式碼（Google Apps Script）

1. 在剛剛的試算表上方選單，點 **擴充功能 → Apps Script**
2. 會開啟一個新分頁，把裡面預設的程式碼**全部刪除**
3. 打開這個專案裡的 `google-apps-script/Code.gs` 檔案，把裡面全部內容複製貼上
4. 建議先修改這一行，換成你自己的管理密碼（不要用預設的 0000）：
   ```js
   const ADMIN_CODE = "0000"; // 改成你自己的密碼
   ```
5. 點上方 **儲存**（磁片圖示）

---

## 第三步：部署成網址

1. 點右上角 **部署 → 新增部署作業**
2. 類型選擇「**網頁應用程式**」（如果沒看到，先點齒輪圖示選擇）
3. 設定：
   - 說明：隨意填寫
   - 執行身分：**我**
   - 誰可以存取：**任何人**
4. 點 **部署**，第一次會要求你「授權」，跟著畫面允許即可
   - 如果出現「Google 尚未驗證這個應用程式」的警告畫面，屬正常現象（因為這是你自己寫的小工具），點左下角「進階」→「前往（不安全）」即可繼續
5. 完成後會出現一組網址，長得像：
   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```
   **請完整複製這組網址**，下一步會用到。

> ⚠️ 之後如果你有修改 `Code.gs` 的內容，都需要重新「新增部署作業」（或用「管理部署作業」更新現有版本），單純儲存不會讓網站生效。

---

## 第四步：把網址貼進網站程式碼

1. 打開這個專案裡的 `src/App.jsx`
2. 找到這一行（在檔案偏前面的位置）：
   ```js
   const APPS_SCRIPT_URL = "請貼上你的Google Apps Script網址";
   ```
3. 把引號中間換成你剛剛複製的網址，例如：
   ```js
   const APPS_SCRIPT_URL = "https://script.google.com/macros/s/AKfycb.../exec";
   ```

---

## 第五步：本機測試（確認畫面正常）

需要先在電腦安裝 [Node.js](https://nodejs.org/)（下載 LTS 版本安裝即可）。

打開終端機（Mac 是「終端機」，Windows 是 PowerShell），切換到專案資料夾後執行：

```bash
npm install
npm run dev
```

執行後會顯示一個網址（通常是 `http://localhost:5173`），打開瀏覽器貼上，測試看看：
- 選日期 → 選時段 → 填資料 → 送出，看是否成功
- 打開你的 Google 試算表，確認有沒有自動新增一列資料
- 回到網站點「管理者專用：取消預約」，輸入你設定的密碼，確認能看到剛剛送出的完整資料

---

## 第六步：免費部署到網路上（Vercel）

1. 到 [github.com](https://github.com) 註冊帳號（如果還沒有）
2. 建立一個新的 repository（名稱隨意，例如 `temple-booking`）
3. 把整個專案資料夾上傳上去（可以用 GitHub 網頁版的「上傳檔案」功能，把資料夾內容拖上去即可，不用學指令）
4. 到 [vercel.com](https://vercel.com) 用 GitHub 帳號登入
5. 點 **Add New → Project**，選擇你剛剛建立的 repository
6. 其他設定保持預設，直接點 **Deploy**
7. 幾十秒後會拿到一個網址，例如 `temple-booking.vercel.app`——這就是顧客可以直接打開、不用登入就能填寫的正式網址

---

## 之後要注意的事

- **管理密碼**：目前寫在 `Code.gs` 裡的 `ADMIN_CODE`，只有你自己知道網址、也只有你會去改這個檔案，所以算是可接受的簡易保護方式。如果未來覺得不夠安全，可以再升級成更完整的登入機制。
- **想要改設計/文字**：直接修改 `src/App.jsx` 裡對應的文字或顏色變數（檔案最上面有一排顏色設定），改完存檔，`npm run dev` 就能立刻看到效果。
- **想要看所有預約總覽**：其實你也可以直接打開 Google 試算表本身查看所有資料，會比透過網站後台更完整（例如可以篩選、排序、匯出 Excel）。
